# A1 图标资产

本目录使用 Bootstrap Icons v1.11.3 的原始 SVG 文件：`list`、`gear`、`volume-up`、`arrows-fullscreen`、`chevron-right`。

Phase 2（真实牌桌接入）按同一规则补充官方同版本图标：`text-indent-left`（Header 汉堡菜单）、`journal-text`（牌局记录入口）、`volume-mute`（音效关闭状态）。来源与许可不变，未修改路径数据。

- 来源：https://github.com/twbs/icons/tree/v1.11.3
- 许可：MIT
- 使用规则：线性图标优先，视觉尺寸 16–18px，点击区域不小于 36px；不混用 emoji、文字字符或手绘 SVG 作为界面图标。

未修改 SVG 路径数据；样稿页仅通过 CSS 统一明度与透明度。
