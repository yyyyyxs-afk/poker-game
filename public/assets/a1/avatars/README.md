# A1 像素头像样稿

三张头像均由 OpenAI 内置 ImageGen 分别生成，再机械缩放为 128 × 128 PNG。共同约束：2008–2012 年 QQ 空间 / 贴吧非主流像素头像、低饱和、透明背景、硬像素边缘、32–64px 仍可辨认；禁止动物、emoji、NFT、强赛博霓虹和现代手游立绘。

| 文件 | 角色差异 | Alpha |
| --- | --- | --- |
| `avatar-blue-headphones.png` | 深蓝短发、白色头戴耳机、冷静表情 | 0 / 255 |
| `avatar-magenta-asym.png` | 暗洋红不对称短发、黑色发夹、克制半笑 | 0 / 255 |
| `avatar-red-cap.png` | 暗红刺发、黑色反戴帽、略顽皮表情 | 0 / 255 |

生成时使用的完整提示词保留在本阶段交付记录中；本目录文件是已经人工查看并用于检查页的最终样稿。
