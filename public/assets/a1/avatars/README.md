# A1 像素头像

六张头像均由 OpenAI 内置 ImageGen 分别生成，再机械缩放为 128 × 128 PNG。共同约束：2008–2012 年 QQ 空间 / 贴吧非主流像素头像、低饱和、透明背景、硬像素边缘、32–64px 仍可辨认；禁止动物、emoji、NFT、强赛博霓虹和现代手游立绘。

| 文件 | 角色差异 | Alpha |
| --- | --- | --- |
| `avatar-blue-headphones.png` | 深蓝短发、白色头戴耳机、冷静表情 | 0 / 255 |
| `avatar-magenta-asym.png` | 暗洋红不对称短发、黑色发夹、克制半笑 | 0 / 255 |
| `avatar-red-cap.png` | 暗红刺发、黑色反戴帽、略顽皮表情 | 0 / 255 |
| `avatar-teal-ponytail.png` | 暗青高侧马尾、银色发夹、友好表情 | 0 / 255 |
| `avatar-amber-beanie.png` | 暗琥珀发、芥末色针织帽、圆框眼镜 | 0 / 255 |
| `avatar-violet-bangs.png` | 暗紫齐刘海、高领上衣、安静表情 | 0 / 255 |

前三款提示词见 `prompts.md`，后三款提示词见 `prompts-phase6.md`；本目录 PNG 均已人工检查尺寸、透明通道和小尺寸辨识度。
