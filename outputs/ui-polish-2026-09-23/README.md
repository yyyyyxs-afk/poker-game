## 键盘交互返工

桌面浏览器复现发现，设置和复盘打开后按 Tab 可以移到牌桌控件；设置和复盘也没有自己的 Escape 关闭处理。玩法说明已有 Escape 关闭和焦点返回，本轮保留该交互并加入同一焦点边界管理。

- 设置、复盘和玩法说明都把 Tab 与 Shift+Tab 限制在当前最上层可见对话框。按 Escape 只关闭最上层对话框；关闭后优先回到打开入口。入口因牌局状态更新而隐藏时，焦点回到可见菜单按钮。
- 设置弹窗补齐对话框语义；打开后焦点进入起始筹码输入框，取消、保存成功及 Escape 关闭后返回房管设置按钮（若仍可见）。
- 复盘在下一局状态到达时自动收起，焦点回到本局详情按钮；若当前牌局没有可回看的结果，则回到可见菜单按钮。
- Esc 只有在对话框打开时才由弹窗管理接管；普通状态下聊天输入保持焦点。加注输入框现有 Enter 确认逻辑保持不变，并纳入界面检查。

本地独立端口 3456 的 Chromium 实测。键盘和触屏关闭测试通过页面内临时结算夹具打开正式复盘界面，牌桌仍由本地测试服务器提供；视口尺寸以页面 `innerWidth`、`innerHeight` 读数为准。

| 场景 | 结果 |
