# 德州扑克在线游戏 · 功能与技术现状说明

> 整理日期：2026-08-28
> 用途：提供给外部 AI 作为项目背景资料。当前计划：按「方案 E · 澳门豪华风」全面重做前端。

---

## 一、项目概况

- **名称**：poker-game，多人在线无限注德州扑克（No-Limit Texas Hold'em）
- **技术栈**：Node.js 22 + Express 5 + Socket.IO 4；客户端为原生 HTML/CSS/JS（无框架）
- **规模**：服务端单文件 `server.js` 约 1000 行；客户端 `public/`（index.html + client.js 约 720 行 + style.css）；冒烟测试 `test/smoke.test.js`
- **部署形态**：本机 `node server.js` 运行（端口可配，默认 3000）；外网联机用 cloudflared 快速隧道（免注册随机域名）。**无云部署、无持久化**（房间数据在内存，进程重启即清空，关机即停服）

## 二、核心玩法与规则（已全部实现）

- 完整牌局流程：发牌 → 翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌
- 无限注动作：弃牌 / 过牌 / 跟注 / 加注（含最小加注额校验）/ 全押（含不足最小加注时的全押跟注处理）
- 边池（Side Pot）：按每位玩家总投入自动分层构建，支持多人全押的复杂场景；平分时余数逐个分配
- 牌力评估：7 选 5 暴力枚举所有组合，含 A-5 轮子顺；返回 `best5` 用于摊牌时高亮赢家最优 5 张牌
- 行动超时 45 秒自动过牌/弃牌；摊牌后 20 秒自动开下一局（可手动跳过）
- 2–6 人同桌，4 位数字房间码邀请制，支持 `?room=1234` 链接直入
- 房主可在等待阶段配置起始筹码 / 小盲 / 大盲（带校验，如起始筹码 ≥ 大盲 × 20）

## 三、房间与玩家系统

- 断线重连：同名 + token 匹配自动恢复座位；刷新页面即时接管原座位（token 校验防冒名劫持）
- 重买：筹码输光后在局间补充（重买金额=起始筹码）
- 暂离 / 坐回：保留座位与筹码，不参与后续局
- 踢人（仅房主）；房主离开自动转移给首位剩余玩家
- 零筹码玩家保留座位不卡局；凑不齐可玩玩家时自动进入等待态（并干净清场）；只剩一名有筹码玩家时判定整场结束（gameOver）

## 四、客户端体验

- 座位围绕椭圆相对布局（自己固定在底部）
- 弃牌两段点击确认防误触
- 表情快捷互动（8 个白名单表情，1 秒限频），座位头像冒泡动画
- Web Audio 合成音效（发牌/下注/轮到你/胜利，可开关）；行动振动反馈（navigator.vibrate）
- 记住昵称与分房间 token（localStorage）
- 公共牌增量发牌动画、底池变化 bump 动画、加注 toast 提示、本局总投入显示
- 结算面板：多池分层展示、赢家牌型中文名 + 最优 5 张高亮、下一局倒计时
- 断线全屏遮罩提示，恢复后自动回座
- 响应式适配手机竖屏/横屏（存在已知问题，见第八节）

## 五、关键技术设计（实现要点）

1. **服务端唯一权威**：客户端只渲染状态、提交动作，所有判定在服务端，天然防作弊
2. **个性化状态视图**：`sanitizeState` 为每个玩家生成专属视图——只有自己的底牌是明牌，对手底牌为 null；摊牌后全部公开
3. **座位下标稳定性**：玩家离开只打 `left` 标记、绝不把数组槽位置 null（下标被 `turnSeat` / `youSeat` / 行动队列 / 客户端渲染共同引用）
4. **canAct 判定**：`!folded && !allIn && connected && chips > 0 && inHand && !sittingOut`
5. **筹码守恒（权威字段 `economyTotal`）**：玩家入座/重买时增加，离座清退时扣除；任意时刻 `Σ(玩家chips + 玩家totalBet) === economyTotal`，冒烟测试按此断言
6. **局间调度器 `scheduleNextHandIfReady`**：能凑齐人就排 20 秒定时器；有零筹码玩家在等重买就不排；实在没人能玩就 gameOver
7. **静态资源 no-cache**：避免浏览器「新 client.js + 旧 index.html」混搭导致渲染崩溃

## 六、Socket 事件协议

客户端 → 服务端：`create_room` / `join_room` / `start_game` / `next_hand` / `action`（fold/check/call/raise/allin）/ `rebuy` / `update_settings` / `sit_out` / `sit_back` / `kick_player` / `emoji` / `leave_room`

服务端 → 客户端：`state`（全量状态推送，每次变化即推）/ `emoji` / `kicked`

`state` 主要字段：房间信息（code/stage/handNumber）、设置（settings）、座位索引（dealerSeat/turnSeat/youSeat）、公共牌、pot/currentBet/minRaise、gameOver/economyTotal/results/revealed、日志（最近 12 条）、玩家数组（含 chips/bets/状态标记/hole 可见性控制）

## 七、近期修复的重要 Bug（2026-08-27/28，均已回归验证）

1. **筹码不守恒回归**：`startHand` 在「人数不足」提前返回分支未清上一局残留的 `totalBet`，导致等待态筹码合计超发一倍 → 已修：该分支先完整清场再广播
2. **断线软锁（严重）**：断线处理先改 `connected` 再判 `canAct`，导致「离线自动弃牌」成为死代码；若断线者正轮到行动，`turnSeat` 被置 -1 且无任何机制恢复 → **全桌永久卡死**。已修：先计算 `wasActable` 再置离线；重连时 `resumeStuckTurn` 自动恢复冻结的行动轮
3. rebuy 时序修正：先回执后广播，保证客户端「到账通知」与「新筹码状态」有序
4. 冒烟测试健壮化：行动驱动改用最新状态复核消除竞态误报；输光自动重买 + 房主重开纳入自动化覆盖；守恒断言切换到服务端 `economyTotal`。连跑 25+ 轮全绿

## 八、UI 现状与重做计划

**现状风格**：浅紫柔和风。已诊断的问题：
- 全页同色系（背景/桌沿/呢面都是紫），牌桌缺乏存在感
- 牌面简陋（无角标版式）、桌心空、筹码数字无 tabular 字体
- 座位信息竖排挤压重叠；下注不像筹码
- 手机端页面超出一屏需滚动，操作按钮可能被压到折叠线以下
- 行动玩家高亮弱（仅头像外圈脉冲）、无行动倒计时提示
- 结算弹窗全屏遮挡牌桌，多池重复渲染 7 张牌冗长

**已确定方向**：**方案 E · 澳门豪华风** —— 黑漆描金桌沿 + 酒红呢面 + 金色点缀，桌面下注用立体筹码堆、座位用桌牌式铭牌、扑克牌用角标版式、环境聚光效果。效果图存于 `public/mockups/e-casino-macau.html`（同目录另有 A/D/F 等备选方案效果图）

**重做计划**：全面重做前端（style.css + index.html 结构 + client.js 渲染层），同时修复上述体验问题（手机一屏放下、行动倒计时进度条、结算改侧滑不遮挡、发牌/筹码动画增强）。**Socket 协议与服务端保持不变**（前端重做不动后端）。

## 九、运行方式与已知边界

```bash
npm install --registry=https://registry.npmmirror.com
npm start                      # 默认 3000，PORT 环境变量可改
npm test                       # 需先起服务器；TEST_URL 可指地址
tools\cloudflared.exe tunnel --url http://localhost:3000 --no-autoupdate   # 外网联机
```

已知边界：无持久化（重启清房）、无用户鉴权体系（同名+token 即认人）、无观战模式、无聊天、无房间 TTL 回收、本机部署关机即停（上云需另行部署到 Render/Railway/Fly.io 等支持 WebSocket 的平台）。
