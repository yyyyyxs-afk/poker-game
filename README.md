# 多人在线德州扑克（Poker Game）

基于 **Node.js + Express + Socket.IO** 的多人在线无限注德州扑克（No-Limit Texas Hold'em）游戏。服务端为权威逻辑节点，客户端仅负责渲染与输入，天然防作弊。

## 功能特性

- 🎴 完整牌局流程：发牌 → 翻牌前 → 翻牌 → 转牌 → 河牌 → 摊牌
- 👥 2–6 人同桌，6 位字母数字邀请码（排除 0/O/1/I/L 易混字符）邀请制入房
- 🔗 等待区一键邀请：手机调用系统分享，电脑自动复制带房号的邀请链接
- 🔒 房主可锁定房间，阻止新玩家加入，同时保留原玩家断线重连能力
- 💰 无限注规则：跟注 / 加注 / 全押 / 过牌 / 弃牌，最小加注额校验；快捷下注（1/3、1/2、2/3、满池）
- 🏆 边池（Side Pot）自动分层分配，支持多人全押的复杂底池
- 🔁 断线保护窗口（8 秒内不判负，重连恢复剩余行动时间）；同名 + token 重连自动恢复座位
- ⏱ 行动超时自动过牌/弃牌（20/30/45/60 秒可选）；摊牌后局间倒计时（5/10/20 秒可选）
- 🧾 本场战绩：买入 / 筹码 / 盈亏 / 手数 / 胜场，全场盈亏恒为零和
- 🔐 crypto 密码学安全洗牌；加入限频防扫房
- 🛡️ 所有 Socket 请求统一校验；token 防离线座位冒名；弃牌者底牌不会在摊牌时泄露
- ☠️ 有人赢光全部筹码时整场结束（Game Over），可配置禁止重买
- 📱 响应式前端（320/375/430 宽度无横向滚动），手机浏览器可直接游玩

## 快速开始

```bash
# 1. 安装依赖（国内网络建议加镜像）
npm install --registry=https://registry.npmmirror.com

# 2. 启动服务器（默认端口 3000）
npm start

# 或指定端口
PORT=8080 npm start
```

浏览器打开 `http://localhost:3000`，输入昵称创建房间，把邀请码告诉朋友即可开局。

> 要求 Node.js ≥ 18。
> 想要**固定网址**、朋友随时可玩（本机关机也行）？看 [云端部署指南.md](云端部署指南.md)（Render 免费档，一次配置永久链接）。

## 运行测试

运行一条命令即可完成全量回归：

1. **规则测试**：洗牌、昵称与 token、7 张牌牌力、平分及边池；
2. **几何测试**：320/375/手机横屏/桌面布局下，穷举 2–6 人席位与下注圆片；
3. **联机测试**：自动启动隔离端口服务，验证 2/3/6 人对局、筹码守恒、断线重连、离场、请求防护、隐私和重复请求。

```bash
npm test
```

`npm test` 会自动选择空闲端口并在结束后关闭临时服务，不会占用正在游玩的默认 3000 端口。需要单独调试时可使用：

```bash
npm run test:rules
npm run test:geometry

# 联机测试仍支持连接手动启动的服务
# Windows PowerShell，终端 1
$env:PORT='3456'; npm start
# 终端 2（smoke 默认连接 3456）
npm run test:smoke

# macOS / Linux，终端 1
PORT=3456 npm start
# 终端 2
npm run test:smoke
```

## 核心设计

| 模块 | 说明 |
| --- | --- |
| 牌力评估 | `evaluate7(cards)` 从 7 张牌中取最优 5 张，返回可字典序比较的分值数组 `[类别, 关键点数...]`，类别 0–8 对应高牌到皇家同花顺 |
| 边池分配 | `computePots(room)` 按每人总投入分层切出主池/边池，弃牌者保留投入但丧失争夺资格 |
| 座位索引 | `turnSeat` / `youSeat` / 客户端布局均按数组下标引用座位，玩家离开只打标记、下一局开始时统一清场，避免索引漂移 |
| 状态广播 | 服务端对每个玩家生成个性化视图（只发自己的底牌），摊牌后向所有人公开 |

## 已知边界

- 房间数据保存在内存中，进程重启即清空（无持久化）。
- 未做账号体系；身份是保存在浏览器本地的房间 token，清理浏览器数据后无法恢复原座位。
